# Карта объекта — М-4 «Дон», км 398+631 и км 473+479

Лист «Рисунок 1» (схема расположения объекта) для:

> **Автомобильная дорога М-4 «Дон» Москва – Воронеж – Ростов-на-Дону – Краснодар – Новороссийск.
> Капитальный ремонт путепровода через ж/д на км 398+631 (альтернативное направление,
> проезд по г. Елец) Липецкая область и путепровода через а/д на км 473+479 Воронежская область.**

Оформление повторяет образец `Рисунок1.png`: обзорная карта-подложка, круговые
выноски-увеличения со стрелками и панель «УСЛОВНЫЕ ОБОЗНАЧЕНИЯ» с экспликацией.

---

## Как открыть

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# затем http://localhost:8080/
```

Страница подтягивает тайлы карты из интернета — нужен доступ в сеть у браузера.

## Как сохранить PDF

Кнопка **«Печать / Сохранить PDF»** (или `Ctrl+P`) →
«Сохранить как PDF», размер бумаги **A3 альбомный** (или A4, если переключён формат),
поля — «Нет», «Фоновая графика» — включить.

## Положение сооружений

| № | Сооружение | Пикетаж | Координаты WGS-84 | Субъект РФ | Как определено |
|---|------------|---------|-------------------|------------|----------------|
| 1 | Путепровод через ж/д | км 398+631 | **52.56352, 38.67952** | Липецкая обл., Елецкий м. о. | по пикетажу альтернативного направления; единственный путепровод через ж.-д. линию Юго-Восточной ж. д. на этом ходу — **ориентировочно, требует сверки с ведомостью ИССО** |
| 2 | Путепровод через а/д | км 473+479 | **52.00772, 39.21242** | Воронежская обл., Рамонский р-н, Комсомольское с/п | интерполяция между километровыми столбами км 473 и км 474 (OSM `highway=milestone`); совпала с существующим путепроводом с точностью **≈ 7 м** |

Координаты правятся в панели справа (поля «Широта/Долгота») или перетаскиванием
кружка с номером прямо на карте. Ссылки «Яндекс / OSM / СКДФ» в панели открывают
точку во внешних сервисах для сверки.

## Структура

```
index.html            лист + панель управления
assets/data.js        ВСЕ данные листа: тексты, координаты, подложки, геометрия трасс
assets/app.js         сборка карт, выносок, выносных линий, легенды
assets/styles.css     оформление листа и печати (A3/A4 альбомный)
vendor/leaflet/       Leaflet 1.9.4 (локально, без CDN)
Рисунок1.png          образец оформления
Карта — ФГИС СКДФ.pdf исходная выкопировка заказчика
```

Почти всё настраивается в `assets/data.js`: заголовок, подпись рисунка,
координаты и подписи объектов, масштаб выносок, набор подложек, рамка обзора.

## Подложки

| Ключ | Что это |
|------|---------|
| `esriTopo` | Esri World Topographic — по умолчанию, ближе всего к атласной подложке ФГИС СКДФ |
| `openTopo` | OpenTopoMap — рельеф с горизонталями |
| `osm` | OpenStreetMap стандарт |
| `voyager` | CartoDB Voyager — светлая, малошумная |
| `esriImagery` | космоснимок Esri — удобно для выносок |

Галочка «Тонировать под атлас» добавляет к тайлам мягкий сепия-фильтр, чтобы
подложка читалась как лист атласа автодорог (как на образце).

## Внешние источники (подгружаются браузером и кэшируются в localStorage)

* геометрия трассы М-4 и альтернативного направления — OSRM (`router.project-osrm.org`);
  при недоступности используется вшитая генерализованная геометрия;
* границы Липецкой и Воронежской областей — Nominatim (`polygon_geojson`);
  при недоступности просто не рисуются.
